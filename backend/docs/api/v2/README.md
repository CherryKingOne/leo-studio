# API v2 接口文档（预留）

本目录用于 **Leo Studio 后端 v2 版本**的接口文档，对应服务前缀 `/api/v2`。

## 当前状态

**v2 接口尚未实现。** 后端当前仅注册 `/api/v1` 路由（见 `backend/src/app.rs`），
代码中不存在任何 `/api/v2` 路由或调用。本目录作为版本化文档结构的预留位，
待 v2 接口设计并落地后，按以下规则补充：

```text
v2/
├── README.md          # 本文件
├── system/            # 系统类接口
├── text-files/        # 文本文件类接口
└── projects/          # 项目类接口
```

- 每个版本目录下按**路由模块**建立文件夹（如 `projects`、`text-files`）。
- 每个接口对应**一个 Markdown 文件**，文件名使用接口语义命名（如 `create.md`）。
- 每份文档包含：接口地址、请求参数、响应字段、代码示例、成功/失败响应示例。
